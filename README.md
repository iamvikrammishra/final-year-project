# SkillSync 
SkillSync - The World's Work Marketplace (Frontend only. Inspired by Upwork, I built this freelance marketplace UI.

### How to run 💻
Please follow the below instructions to run this project in your machine:
## Getting Started

1. Clone this repository :
  ```bash
  git clone https://github.com/iamvikrammishra/final-year-project.git
```
2. install dependencies and devDependencies:
```bash
npm install
# or
yarn install
```

3. run your development server
```bash
npm run dev
# or
yarn dev
```
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result
